# Stationery Box Game v2

Changes from v1:
- Removed the random “Put the ___ in the box” challenge.
- Redesigned stapler, glue stick, pencil sharpener, and eraser as custom SVG illustrations.
- Desktop layout is fitted to one screen to avoid vertical scrolling.
- Added selection and deletion:
  - Click/tap an item inside the box to select it.
  - Click **Delete Selected**, or press Delete/Backspace on a keyboard.
- Students can still drag or tap items into the box.
- Double-click an item to hear the English word.
- Save/Load uses the same browser/device.

Replace the old `index.html`, `style.css`, and `script.js` in GitHub with these v2 files.
