# Stationery Box Game v3

New in v3:
- Stationery placed inside the box starts larger.
- Hover over an item inside the box and use the mouse wheel:
  - Scroll up = bigger
  - Scroll down = smaller
- The item is automatically selected while resizing.
- Size range is limited so items cannot become impossibly tiny or huge.
- Saved layouts now remember each item's size.
- Existing delete, drag, save, load, and no-scroll desktop layout are kept.

Replace your old `index.html`, `style.css`, and `script.js` with the v3 files.
