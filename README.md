# Stationery Box Game

A classroom-friendly drag-and-drop vocabulary game for GitHub Pages.

## Files
- `index.html`
- `style.css`
- `script.js`

## How to publish on GitHub Pages
1. Create a new GitHub repository, for example: `stationery-box-game`.
2. Upload the three website files to the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will give you a public URL such as:
   `https://your-username.github.io/stationery-box-game/`

## Game controls
- Drag an item into the box, or tap/click an item to add it.
- Double-click an item to hear its English word.
- Use **Next Challenge** to generate a new instruction.
- **Save** stores the current arrangement in the browser.
- **Load** restores it on the same device/browser.
- **Reset** clears the box.

You can edit the vocabulary list near the top of `script.js`.
